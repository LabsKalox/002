# Vocal Riser by Kalox — prompts do Veo 3 (formato BankMaster: apresentador + plugin funcionando)

Roteiro:
- Take 1: "Sabe aquele vocal subindo antes do drop no Afro House? Olha o que meu plugin faz."  → corta para o plugin gerando o riser (com o som)
- Take 2: "É o Vocal Riser da Kalox. Joga o vocal, escolhe o preset e gira o botão."  (no Veo: "Vôcal Ráizer da Kálox")
- Take 3: "Ainda liga chorus, tremolo ou efeito de telefone. Comenta RISER que eu te mando na DM."

Quadro inicial: `frame-inicial-estudio-preto.png` com o fundo trocado por LED verde neon (prompt "somente o fundo"
do `../bankmaster/VARIACOES-CENARIO.md`, fundo: painéis pretos ripados com linhas de LED verticais verde neon,
monitores desfocados nas laterais).

Personagem, roupa, câmera e estrutura dos prompts: iguais a `../bankmaster/VEO-PROMPTS-V2.md`, com o trecho do
estúdio "(parede de painéis pretos ripados com linhas de LED verticais verde neon, monitores de estúdio desfocados
nas laterais)" e os gestos: T1 mão subindo como som crescendo → dedo → aponta para baixo; T2 mão no peito →
"joga para dentro" + escolhe → gira um botão no ar; T3 conta os efeitos → aponta → "me chama" + piscadinha.

Plugin funcionando: gravação de tela (~10 s) do Vocal Riser gerando o riser, com o som; alternativa: animar
`assets/brand/vocal-riser-ui.png` com um áudio real de riser gerado pelo plugin.
